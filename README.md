## 1. Project Overview & Product Vision
The **Student Record and Academic Management Platform (SRAMP)** is a scalable, cloud-ready, web-based platform developed under the **Scrum Framework** to resolve institutional inefficiencies in academic administration, paper-based attendance, and manual grade calculations.

### Product Vision Statement
> *"Develop a secure, high-performance, and user-friendly Student Record and Academic Management Platform that enables educational institutions to efficiently manage student records, attendance, academic performance, course registration, and reporting through a scalable web-based application."*

## 2. Key Modules & Functional Epics Delivered

| Epic ID | Epic Name | Key Capabilities Delivered | Sprint |
|---|---|---|---|
| **EPC-001** | **Student Management** | Digital admissions, real-time search & filter, profile dossier, update, and safe deletion. | Sprint 2 |
| **EPC-002** | **Course Management** | Course catalog, credit assignments, faculty allocation, and batch student enrollment. | Sprint 3 |
| **EPC-003** | **Attendance Management** | 1-click bulk attendance ("Mark All Present"), toggle P/A/L, automated % rollups, session logs. | Sprint 3 |
| **EPC-004** | **Marks & Academic Performance** | Internal (20) + Midterm (30) + End-Sem (50) matrix, automated letter grades (A-F), CGPA calculation, official printable result sheets. | Sprint 4 |
| **EPC-005** | **Authentication & Security** | Multi-role RBAC (Admin, Faculty, Student) with 1-click persona testing switcher. | Sprint 1 |
| **EPC-006** | **Notifications & Alerts** | Automated early-warning alerts for low attendance (<75%), exam alerts, and result release notices. | Sprint 4 |
| **EPC-007** | **Reporting & Analytics** | Interactive grade distribution curves, attendance compliance charts, and departmental rollup tables. | Sprint 4 |

## 3. Interactive Agile Management Suite (In-App)
Built directly into the web application, accessible via the **Agile Scrum Suite** tab:
1. **Interactive Scrum Board**: 5-column live board (`Backlog` &rarr; `To Do` &rarr; `In Progress` &rarr; `Testing` &rarr; `Completed`) with story points badges, priority tags, and sprint filters.
2. **Sprint Burndown Charts**: Interactive HTML5 Canvas chart displaying Ideal vs. Actual burndown lines for Sprint 1, 2, 3, and 4.
3. **Planning Poker Estimator**: Interactive consensus simulator with Fibonacci cards (1, 2, 3, 5, 8, 13) and multi-developer voting breakdown.
4. **Scrum Ceremonies Simulator**: Interactive Daily Standup viewer (Aarav, Sanya, Rohan, Kavita) answering the 3 Scrum questions, plus Sprint Retrospective board (What Went Well, Challenges, Improvements).
5. **Agile Frameworks Comparison Matrix**: Side-by-side comparative analysis of Scrum, Kanban, XP, Lean, LeSS, SAFe, and Scrum@Scale with institutional recommendation.

## 5. Quick Start & Execution Instructions

### Prerequisites
* **Node.js**: v18.0.0 or higher
* **npm**: v8.0.0 or higher

### Installation & Run
1. Navigate to the project root directory:
   ```bash
   cd "c:\Users\vs035\OneDrive\Desktop\DevOps project2"
   ```
2. Install dependencies (if not already installed):
   ```bash
   npm install
   ```
3. Launch the live server:
   ```bash
   npm start
   ```
4. Open your web browser and navigate to:
   ```
   http://localhost:3000
   ```
